# Contributing

Emerald's code is published here from a private working tree at each release, as one commit named `Emerald <version>` that replaces the tree whole. So this repository takes issues, not merges.

- **A bug or an idea**: open an issue. The bug template asks for the version, the arch and the logs.
- **A change**: a pull request is welcome as a way to show it. It is read, and if it is taken it is applied by hand to the working tree and arrives here with the next release; the pull request itself is then closed rather than merged.

Building and testing are in `docs/HANDBOOK.md`. `CLAUDE.md` holds the same notes for a Claude Code session. By opening a pull request you agree that your change may be published under the MIT licence in `LICENSE`.
